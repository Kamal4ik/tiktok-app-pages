Privacy Policy

Last updated: October 2026

1. Overview

TG TikTok Uploader ("we", "our", or "us") is an automated personal integration service designed to upload video content from a Telegram interface to TikTok via official APIs.

2. Information We Collect

We only request permissions necessary to publish video content on behalf of the user (e.g., access tokens provided via TikTok OAuth). We do NOT collect, sell, or store personal user data, passwords, or contact details.

3. How We Use Data

Access tokens are used solely to authenticate requests sent to TikTok Content Posting API to publish user-submitted videos.

4. Data Sharing and Security

We do not share any user data with third parties. All API interactions are conducted securely over encrypted HTTPS connections.

5. Contact

For questions regarding this policy, please contact the developer via GitHub repository issues.
