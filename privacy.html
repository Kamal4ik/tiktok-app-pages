Privacy Policy

Last updated: October 19, 2026

1. Overview

This Privacy Policy explains how CrossPost Bot ("we", "our", or "us") processes user data when integrating Telegram interface with TikTok services via official TikTok Content Posting APIs.

2. Information We Access

We believe in strict data minimization. We only request permissions necessary to execute core user-requested functionalities:

  • TikTok OAuth Access Tokens: Granted securely via official TikTok login to authenticate video uploads on your behalf.
  • Basic Profile Identifiers: Anonymous OpenID provided by TikTok API to associate authorized sessions.
  • Media Files: Video files temporarily processed during upload requests from Telegram.

3. Data Storage & Retention

We do not store passwords, account credentials, or uploaded video content on long-term databases:

  • Temporary Processing: Media files submitted for uploading are held temporarily during transmission and deleted immediately after API confirmation.
  • Token Protection: OAuth access tokens are stored using encrypted environment configurations solely to maintain API authorization.

4. Third-Party API Services

Our service interacts directly with official third-party services:

  • TikTok Open API: Subject to TikTok Privacy Policy.
  • Telegram Bot API: Subject to Telegram Terms and Privacy Guidelines.

5. Data Revocation & Deletion Requests

Users maintain full control over account access at any time:

  • You can revoke our access token directly in your TikTok account settings under Security & Permissions → Authorized Apps.
  • Upon access revocation, all associated session data is invalidated permanently.

6. Children's Privacy

Our service does not knowingly collect or solicit personal information from individuals under the age of 13 (or local legal minimum age).

7. Contact

For questions or data deletion queries regarding this policy, please open an issue in the official GitHub project repository.
